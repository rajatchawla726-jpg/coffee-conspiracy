THE COFFEE CONSPIRACY — iPhone-friendly build

IMPORTANT
1. Open index.html in a code editor.
2. Replace both occurrences of YOUR_INSTAGRAM_USERNAME with your Instagram handle (without @).
3. Publish the folder as a static website using Netlify Drop or another HTTPS static host.
4. Open the resulting public HTTPS URL on an iPhone. Do not test by opening the HTML in the iPhone Files preview; that preview may not run JavaScript.
5. Send the public website URL to the other person.

This build removes WhatsApp links, adds Instagram DM/profile links, adds iPhone safe-area spacing, and includes a background fallback for older Safari versions.
